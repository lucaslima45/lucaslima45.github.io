Desenvolvi uma agenda digital simples utilizando HTML, CSS e JavaScript puro, com foco em praticar a manipulação do DOM e a lógica de programação. O usuário pode adicionar, editar e excluir compromissos, com os dados sendo armazenados localmente no navegador através do localStorage. O layout foi construído com CSS flexível e responsivo, garantindo boa usabilidade em diferentes dispositivos. Esse projeto me permitiu aplicar conceitos fundamentais de front-end e reforçar a interação entre estrutura, estilo e comportamento.

Inclui funcionalidades como filtro, marcar tarefas já realizadas, apagar, editar, e adicionar.
